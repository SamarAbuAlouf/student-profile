Student Profile
Description

This project is a simple Python program that displays a student profile. It includes the student's name, major, university, hobby, career goal, and a second programming language.

How to Run the Program
Make sure Python is installed on your computer.
Open the project folder in a terminal.
Run the following command:
python main.py

The student profile will then be displayed in the terminal.
